# Codveda Business Analytics Internship

This repository contains two business analytics projects completed during my Codveda Technologies internship. The projects use the datasets supplied for the internship and focus on data analysis, business intelligence, SQL, statistical analysis, and predictive analytics.

## Projects

### Project 1: Social Media Sentiment and Engagement Analysis

This project analyzes 732 supplied social media records from Instagram, Twitter, and Facebook.

Main work completed:
- Data cleaning and validation
- Descriptive statistics and exploratory data analysis
- Sentiment, platform, country, and time analysis
- Correlation and simple linear regression
- Statistical testing
- Excel analysis and charts
- Power BI dashboard
- MySQL business queries and query optimization

Key results:
- Total records: 732
- Missing values: 0
- Duplicate rows: 0
- Positive sentiment: 64.75%
- Negative sentiment: 26.64%
- Neutral sentiment: 8.61%
- Average Likes: 42.90
- Average Retweets: 21.51
- Instagram posts: 258
- Twitter posts: 243
- Facebook posts: 231
- Likes and Retweets correlation: 0.998
- Countries represented: 33

Main files:
- `Codveda_Project1_Sentiment_Analysis_FINAL.xlsx`
- `Codveda_Project1_Sentiment_Analysis_FINAL.ipynb`
- `Codveda_Project1_Dashboard.pbix`
- `Codveda_Project1_MySQL_FINAL_SUBMISSION.sql`
- `Codveda_Project1_Final_Report_FINAL.docx`

### Project 2: Customer Churn Prediction

This project uses the supplied telecom churn datasets with 2,666 training records and 667 testing records, giving 3,333 customer records in total.

Main work completed:
- Data quality checks
- Churn analysis
- Data preprocessing
- Logistic Regression
- Decision Tree
- Random Forest
- Model evaluation
- Feature importance analysis
- Business recommendations for customer retention

Key results:

| Model | Accuracy | Precision | Recall | F1-Score | ROC-AUC |
|---|---:|---:|---:|---:|---:|
| Logistic Regression | 85.46% | 47.37% | 18.95% | 0.2707 | 0.8265 |
| Decision Tree | 95.35% | 88.10% | 77.89% | 0.8268 | 0.8799 |
| Random Forest | 94.90% | 92.96% | 69.47% | 0.7952 | 0.9266 |

The combined churn rate is 14.49%, representing 483 of 3,333 customers. For this analysis, the Decision Tree was selected because it produced the highest F1-score and stronger recall than the Random Forest.

Main files:
- `Codveda_Project2_Customer_Churn_FINAL.ipynb`
- `Codveda_Project2_Final_Report_FINAL.docx`
